title: "Top Pages"
description: "The top pages driving organic visibility for a domain, with range-aware change tracking and optional Google overlays."
---

Top Pages shows which URLs on a client’s site are driving organic visibility. It surfaces the pages with the highest estimated traffic value, helping you quickly see where SEO performance is concentrated.

## Date range and device

Top Pages supports a date-range selector (for example, 7/14/30/60/90 days). The range controls:

- The comparison window used for change tracking
- The date window used for Google overlays (when connected)

If Google Search Console is connected, you can also filter by device (All/Desktop/Mobile/Tablet).

## Table columns (DataForSEO)

| Column | Description |
|---|---|
| Page URL | The full URL of the page |
| Change | Movement relative to the selected range: **New**, **Up**, **Down**, or **Lost** |
| Keywords | The number of keywords this page ranks for |
| Avg. Position | Average ranking position across the page’s ranking keywords |
| Visibility | Visibility score (estimated traffic value) for the page |

## Google overlays (optional)

When Google integrations are connected, Top Pages can overlay real performance data.

### Google Analytics 4 (GA4)

| Column | Description |
|---|---|
| Sessions (GA4) | Sessions attributed to this page |
| Bounce Rate (GA4) | Single-page session rate |
| Conversions (GA4) | Conversion events attributed to this page |

<Info>
  GA4 overlays appear only when GA4 is connected and you are viewing **All devices**.
</Info>

### Google Search Console (GSC)

| Column | Description |
|---|---|
| Clicks (GSC) | Clicks from Google search results |
| Impressions (GSC) | Impressions in Google search results |
| CTR (GSC) | Click-through rate |
| Position (GSC) | Average position over the selected window |

## Change tracking

Top Pages uses daily snapshots to support range-aware comparisons. The Change badge is calculated by comparing the latest snapshot to the snapshot at the start of the selected range:

| Badge | Meaning |
|---|---|
| New | The page appears now but did not appear at the start of the window |
| Up | Visibility increased over the window |
| Down | Visibility decreased over the window |
| Lost | The page appeared at the start of the window but no longer appears now |

<Tip>
  Pages marked **Lost** are worth investigating. Cross-reference with Organic Rankings to see if the page’s primary keywords also declined.
</Tip>

## Exporting data

Click **Export CSV** to download the current view. The export respects active range/device filters and includes Google overlay columns when they are visible.

## Data freshness

Top Pages includes multiple data sources. The page shows freshness per source (DataForSEO, GA4, GSC) so you can tell which part of the view is stale.

See [Refresh schedules](/data/refresh-schedules) for timing details.
