RankLyft uses [Vercel Flags](https://vercel.com/docs/flags/vercel-flags) to manage feature flags. Flags are configured in the Vercel dashboard and evaluated at runtime via the `@flags-sdk/vercel` adapter, so toggling a flag takes effect immediately without redeploying.

## Available flags

### `backlinks`

Enables the Backlinks section across the application.

**What it activates:**
- Backlinks page in each website's sidebar (`/{websiteSlug}/backlinks`)
- Backlinks summary card on the website Dashboard
- Backlinks data refresh in the weekly cron job (`/api/cron/refresh-websites`)

**DataForSEO endpoint used:** `backlinks/summary`

**Cost implication:** DataForSEO requires a $100/month minimum commitment to access Backlinks endpoints. Do not enable this flag until you have confirmed that commitment with DataForSEO.

---

### `ai-visibility`

Enables the AI Visibility section across the application.

**What it activates:**
- AI Visibility page in each website's sidebar (`/{websiteSlug}/ai-visibility`)

**DataForSEO endpoint used:** AI-related SERP and content APIs

**Cost implication:** Requires a $100/month minimum commitment to DataForSEO's AI data endpoints. Confirm with DataForSEO before enabling.

---

### `multi-country`

Enables multi-country data on the Domain Overview page.

**What it activates:**
- Multi-country data table on the Domain Overview page

## How flags are evaluated

Flags are defined in `lib/flags-vercel.ts` using the Flags SDK with the Vercel adapter:

```ts
// lib/flags-vercel.ts
import { flag } from "flags/next"
import { vercelAdapter } from "@flags-sdk/vercel"

const adapter = process.env.FLAGS ? vercelAdapter() : undefined

export const backlinksFlag = flag({
  key: "backlinks",
  description: "Enable backlinks analysis feature",
  adapter,
  defaultValue: false,
  decide: () => false,
  options: [
    { value: false, label: "Off" },
    { value: true, label: "On" },
  ],
})
```

When the `FLAGS` environment variable is present (automatically provisioned by Vercel), the adapter connects to the Vercel Flags service and reads the dashboard value. When `FLAGS` is absent (local development without Vercel), flags fall back to `defaultValue`.

## Toggling a flag

1. Go to your Vercel project dashboard.
2. Click **Flags** in the sidebar.
3. Toggle the flag to **On** or **Off**.

The change propagates globally in milliseconds — no redeploy needed.

## Environment variables

Vercel automatically manages two environment variables for the Flags system:

| Variable | Description |
|---|---|
| `FLAGS` | SDK connection key — auto-provisioned when you create your first flag in the dashboard |
| `FLAGS_SECRET` | Used by the Flags Explorer toolbar for development-time overrides |

These do not need to be set manually. For local development, run `vercel env pull` to sync them to `.env.local`.
