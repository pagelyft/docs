RankLyft runs cron jobs configured in `vercel.ts`. All jobs run in the Vercel Production environment only. They do not run on Preview or Development deployments.

## Authentication

All endpoints require an `Authorization: Bearer {CRON_SECRET}` header. Vercel injects this header automatically when triggering cron jobs. If you call these endpoints manually (for testing or a forced run), you must include the header yourself.

```bash
curl https://rank.pagelyft.studio/api/cron/sync-dfs-domain-overview \
  -H "Authorization: Bearer $CRON_SECRET"
```

<Warning>
  Never expose `CRON_SECRET` in client-side code or commit it to version control. Treat it as a password.
</Warning>

## Execution order

The jobs are staggered to reduce overlap and spread vendor API load. On a typical day, the schedule is:

```text
Daily timeline (UTC):
04:00  Sync DataForSEO Domain Overview (300s max)
04:10  Sync DataForSEO Ranked Keywords (300s max)
04:20  Sync DataForSEO Top Pages (300s max)
04:30  Sync DataForSEO Backlinks Summary (300s max)
04:40  Sync DataForSEO AI Visibility (300s max, if enabled)
06:00  Track Positions (300s max)
07:00  Run Scheduled Audits (300s max)
07:30  Sync GSC (300s max)
08:00  Sync GA4 (300s max)
19:30  Sync GSC (300s max)
20:00  Sync GA4 (300s max)
*/30  Recover Audits (runs every 30 minutes)
```

On Mondays and Thursdays, the backlinks details job also runs:

```text
Mon/Thu extras (UTC):
05:00  Sync DataForSEO Backlinks Details (300s max)
```

On Mondays, tracked competitor refresh also runs:

```text
Monday extras (UTC):
05:30  Sync DataForSEO Tracked Competitors (300s max)
```

On the 1st of each month, monthly jobs run:

```text
1st-of-month timeline (UTC):
03:00  Sync DataForSEO Historical Overview (300s max)
03:00  Aggregate GSC (300s max)
06:00  Track Positions
07:00  Run Scheduled Audits
07:30  Sync GSC
08:00  Sync GA4
```

## `vercel.ts` configuration

```typescript
import type { VercelConfig } from "@vercel/config/v1";
export const config: VercelConfig = {
  crons: [
    { path: "/api/cron/sync-dfs-domain-overview", schedule: "0 4 * * *" },
    { path: "/api/cron/sync-dfs-ranked-keywords", schedule: "10 4 * * *" },
    { path: "/api/cron/sync-dfs-top-pages", schedule: "20 4 * * *" },
    { path: "/api/cron/sync-dfs-backlinks-summary", schedule: "30 4 * * *" },
    { path: "/api/cron/sync-dfs-ai-visibility", schedule: "40 4 * * *" },
    { path: "/api/cron/sync-dfs-backlinks-details", schedule: "0 5 * * 1,4" },
    { path: "/api/cron/sync-dfs-competitors", schedule: "30 5 * * 1" },
    { path: "/api/cron/sync-dfs-historical-overview", schedule: "0 3 1 * *" },
    { path: "/api/cron/track-positions", schedule: "0 6 * * *" },
    { path: "/api/cron/run-scheduled-audits", schedule: "0 7 * * *" },
    { path: "/api/cron/sync-gsc", schedule: "30 7 * * *" },
    { path: "/api/cron/sync-gsc", schedule: "30 19 * * *" },
    { path: "/api/cron/sync-ga4", schedule: "0 8 * * *" },
    { path: "/api/cron/sync-ga4", schedule: "0 20 * * *" },
    { path: "/api/cron/aggregate-gsc", schedule: "0 3 1 * *" },
    { path: "/api/cron/recover-audits", schedule: "*/30 * * * *" },
  ],
};
```

<Info>
  Vercel cron jobs use standard cron syntax. The timezone is always UTC. Vercel delivers the request to your serverless function as an HTTP GET with the `Authorization` header set to `Bearer {CRON_SECRET}`.
</Info>

## Manual execution

You can trigger any job manually from the command line.

```bash
# DataForSEO sync (example: Domain Overview)
curl https://rank.pagelyft.studio/api/cron/sync-dfs-domain-overview \
  -H "Authorization: Bearer $CRON_SECRET"

# Daily position tracking
curl https://rank.pagelyft.studio/api/cron/track-positions \
  -H "Authorization: Bearer $CRON_SECRET"

# Scheduled site audits
curl https://rank.pagelyft.studio/api/cron/run-scheduled-audits \
  -H "Authorization: Bearer $CRON_SECRET"

# Google Search Console sync
curl https://rank.pagelyft.studio/api/cron/sync-gsc \
  -H "Authorization: Bearer $CRON_SECRET"

# Google Analytics 4 sync
curl https://rank.pagelyft.studio/api/cron/sync-ga4 \
  -H "Authorization: Bearer $CRON_SECRET"

# GSC data aggregation
curl https://rank.pagelyft.studio/api/cron/aggregate-gsc \
  -H "Authorization: Bearer $CRON_SECRET"

# Stuck audit recovery
curl https://rank.pagelyft.studio/api/cron/recover-audits \
  -H "Authorization: Bearer $CRON_SECRET"
```

<Tip>
  You can also trigger cron jobs from the Vercel dashboard under **Settings > Cron Jobs > Run now**, which injects the auth header automatically.
</Tip>
