"Fresh data" means different things for different SEO metrics. A keyword can move overnight, while backlink indexes often lag by weeks. RankLyft’s schedule reflects those differences.

## Freshness by feature

| Feature | Update frequency | Data type | Effective lag |
|---|---|---|---|
| Domain Overview | Daily (04:00 UTC) | Pre-indexed | Up to 24 hours |
| Historical Trends | Monthly (1st, 03:00 UTC) | Pre-indexed | Up to 1 month |
| Organic Rankings | Daily (04:10 UTC) | Pre-indexed | Up to 24 hours + vendor index age |
| Top Pages | Daily (04:20 UTC) | Pre-indexed | Up to 24 hours + vendor index age |
| Position Tracking | Daily (06:00 UTC) | Live SERP | Up to 24 hours |
| Keyword Overview | On-demand (always live) | Pre-indexed | Vendor index age |
| Keyword Suggestions | On-demand (always live) | Pre-indexed | Vendor index age |
| Related Keywords | On-demand (always live) | Pre-indexed | Vendor index age |
| Competitors (research tool) | On-demand (always live) | Pre-indexed | Vendor index age |
| Keyword Gap | On-demand (always live) | Pre-indexed | Vendor index age |
| Backlinks (summary) | Daily (04:30 UTC) | Pre-indexed | Up to 24 hours + vendor index age |
| Backlinks (details) | Mon/Thu (05:00 UTC) | Pre-indexed | 3–4 days + vendor index age |
| Site Audit | Daily or on-demand | Live crawl | Up to 24 hours |
| AI Visibility | Daily snapshot (04:40 UTC) + on-demand | Live query | Up to 24 hours (snapshot) |

## Understanding freshness and lag

### 1. RankLyft’s sync schedule

For scheduled datasets, RankLyft only updates what you see after the next sync window (or an on-demand refresh). If you need the latest available vendor data right now, use the **Refresh** action on the report page.

### 2. Vendor index age

For pre-indexed datasets (DataForSEO Labs and Backlinks), RankLyft receives whatever is currently in the vendor index. Even with daily sync, the underlying data may be days or weeks behind Google.

<Info>
  Position Tracking avoids vendor index lag by querying live SERPs on a daily schedule.
</Info>

## AI Visibility freshness

AI Visibility data is fetched as:

- A **daily snapshot** (used for trends and “last updated”)
- An **on-demand check** when you manually refresh

Because these are live queries against AI platforms, results can change at any time.

## Backlink freshness

Backlink indexes tend to lag the real link graph. Use backlink data for trend analysis and comparisons, not as a real-time link audit.
