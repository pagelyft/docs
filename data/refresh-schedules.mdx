---
title: "Refresh schedules"
description: "When RankLyft pulls fresh data and how to trigger an on-demand refresh."
---

RankLyft refreshes data on a schedule so your reports stay current without you needing to manually click refresh every day. All scheduled jobs run in **UTC**.

## Daily DataForSEO refresh — starting at 4:00 AM UTC

Most DataForSEO-backed reports refresh daily in the early morning UTC window.

| Data type | Feature | Typical time (UTC) |
|---|---|---|
| Domain overview metrics | Domain Overview | 04:00 |
| Organic keyword set | Organic Rankings | 04:10 |
| Top pages list | Top Pages | 04:20 |
| Backlink summary | Backlinks | 04:30 |
| AI Visibility snapshot (if enabled) | AI Visibility | 04:40 |

<Info>
  These pulls use pre-indexed vendor data (Labs/Backlinks/AI). A “daily sync” does not guarantee the vendor’s index changed since yesterday.
</Info>

## Weekly and monthly DataForSEO refreshes

Some datasets are refreshed less frequently due to cost and volatility.

| Data type | Feature | Schedule (UTC) |
|---|---|---|
| Backlink history + referring domains | Backlinks | Monday + Thursday 05:00 |
| Tracked competitor metrics | Domain Overview (Tracked competitors) | Monday 05:30 |
| Historical overview points | Domain Overview (trend charts) | 1st of month 03:00 |

## Daily live refresh — 6:00 AM UTC

Position Tracking runs live SERP checks daily.

| Data type | Feature |
|---|---|
| Tracked keyword SERP positions | Position Tracking |

## Daily site audit scheduling — 7:00 AM UTC

If you enable a Site Audit schedule for a website, RankLyft checks it daily and starts a crawl when one is due.

| Data type | Feature |
|---|---|
| Scheduled site audits | Site Audit |

## Google data sync — twice daily

If a website has Google integrations connected, RankLyft syncs those sources twice per day:

| Data type | Feature | Schedule (UTC) |
|---|---|---|
| Google Search Console | Organic Rankings, Top Pages overlays | 07:30 and 19:30 |
| Google Analytics 4 | Top Pages overlays, Dashboard cards | 08:00 and 20:00 |

## On-demand refreshes

Most report pages include a **Refresh** action. On-demand refreshes run the same backend sync logic as the scheduled jobs.

<Warning>
  Some refresh actions trigger vendor API calls (DataForSEO and Google). On-demand refreshes can increase vendor usage costs.
</Warning>

## What triggers the first data pull

When you add a new website, RankLyft fetches initial DataForSEO data immediately — it does not wait for the next cron window.
